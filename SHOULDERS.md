# Shoulders

Beacon Web stands on the shoulders of giants. Thank you to the following open source
projects that make this possible:

## Core dependencies

- [React](https://react.dev): UI library
- [React Router](https://reactrouter.com): client-side routing
- [TanStack Query](https://tanstack.com/query): server state, caching and infinite
  queries over the REST API
- [TanStack Virtual](https://tanstack.com/virtual): virtualised lists and tables for
  dense packet views

## Map and charts

- [MapLibre GL JS](https://maplibre.org): the map
- [map-gl-js-spiderfy](https://github.com/nazka/map-gl-js-spiderfy): spreading
  overlapping map markers apart
- [Apache ECharts](https://echarts.apache.org): stats charts

## Internationalisation

- [i18next](https://www.i18next.com) and [react-i18next](https://react.i18next.com):
  translations; see [docs/translations.md](docs/translations.md) to add a language

## Build and style

- [Vite](https://vite.dev): dev server and production build
- [TypeScript](https://www.typescriptlang.org): the language
- [Tailwind CSS](https://tailwindcss.com): styling and theme tokens

## Testing and lint

- [Vitest](https://vitest.dev): test runner
- [Testing Library](https://testing-library.com): component tests
- [jsdom](https://github.com/jsdom/jsdom): DOM for tests
- [ESLint](https://eslint.org): linting

## The network

- [MeshCore](https://github.com/meshcore-dev/MeshCore): the mesh this app observes
